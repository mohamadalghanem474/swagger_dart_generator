# 🧬 Swagger Dart Generator

Professional Clean Architecture code generator for Flutter from Swagger/OpenAPI.

## 🚀 Features
- **Clean Architecture**: Generates Domain, Data, and Presentation layers.
- **No Build Runner**: Generated code is "Vanilla Dart" - no extra generation steps needed.
- **Flexible Patterns**: Support for `feature-first`, `layer-first`, and `simple` architectures.
- **State Management**: Optional generation of Bloc/Cubit and Riverpod providers.
- **OAuth2 Support**: Built-in Bearer Token authentication interceptors.
- **File Upload**: Native support for `MultipartFile` and `FormData`.

## 💻 Installation

```bash
dart pub global activate swagger_dart_generator
```
